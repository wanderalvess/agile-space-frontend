# Atuação: Desenvolvedor Full-Stack Sênior (Expert em CRUD e Gestão de Estado)
# Contexto: 
Implementação do Módulo Admin do Knowledge Hub (Ref. Requisitos RF-03, RF-07, RF-11 e RF-12).

# Tarefa:
Desenvolver as páginas administrativas e as lógicas de backend (Firebase Admin/Firestore) para gestão do sistema:

1. **Gestão de Usuários (RF-03):**
   - Página de listagem e criação de usuários.
   - Lógica de 'Soft-Delete' (setar `ativo: false`) e Reset de Senha (gerar senha temporária e setar `deve_trocar_senha: true`).
   - Bloquear acesso de usuários com `role: 'user'` a estas rotas.

2. **Gestão da Base de Conhecimento (RF-07):**
   - Implementar a interface de 3 níveis: Módulo -> Pasta -> Arquivo.
   - Editor de Markdown (ex: SimpleMDE ou Monaco) para salvar o conteúdo diretamente no Firestore.
   - Gerar Slugs automáticos a partir do nome do módulo/arquivo.

3. **Templates de Chamado (RF-11):**
   - CRUD para `ticket_templates` com campos: nome, instruções_ia (prompt extra) e o template com placeholders `{{campo}}`.

4. **Sistema de Auditoria (RF-12):**
   - Criar utilitário `logger.ts` que insere linhas na coleção `audit_log` para cada ação (login, alteração de KB, reset de senha).
   - Tela de visualização para o Admin ver as últimas 200 ações.

# Saída Esperada:
- Componentes React (Server Components onde possível) para as listagens e formulários.
- Hooks de mutação (usando Firebase SDK) para salvar os dados no Firestore.
- Validação de formulários com Zod.
