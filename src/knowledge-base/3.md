# Atuação: Engenheiro de IA e Desenvolvedor Backend (Node.js/Google Cloud)
# Contexto: 
Implementação do motor de inteligência via Firebase Cloud Functions (Ref. RF-08, RF-09 e Seção 8).

# Tarefa:
Criar a Cloud Function `onSendMessage` que processa a conversa:

1. **Estratégia de Recuperação (RF-08 - Full Context):**
   - A função deve ler TODOS os documentos da coleção `knowledge_base` e concatená-los em uma única string estruturada.
   - Implementar o 'Context Caching' do Gemini (Vertex AI) para enviar a KB apenas uma vez e reutilizá-la em mensagens subsequentes da mesma sessão.

2. **System Prompt (Seção 8):**
   - Injetar instruções rígidas: "Responda APENAS com base nos dados fornecidos. Se não souber, diga 'Não encontrei'. Cite a fonte como **Fonte:** modulo/pasta/arquivo.md".
   - Definir o tom profissional e direto em PT-BR.

3. **Segurança e Rate Limit (RF-14):**
   - Implementar contador de mensagens por UID no Firestore para bloquear excessos (ex: 30 msgs / 5 min).
   - Recuperar chaves de API do Firebase Secrets Manager.

4. **Processamento de Resposta:**
   - Salvar a resposta da IA na sub-coleção `messages`.
   - Extrair as fontes citadas via Regex e salvar no campo `citedSources`.
   - Gerar título automático para a conversa se for a primeira mensagem (RF-05).

# Saída Esperada:
- Código da Cloud Function em TypeScript.
- Configuração do client `@google-cloud/vertexai`.
- Lógica de montagem do prompt dinâmico.
