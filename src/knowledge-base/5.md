# Atuação: Desenvolvedor Backend Sênior (Firebase)
# Contexto: 
Finalização da infraestrutura do Knowledge Hub, focando no upload de anexos e na geração de chamados a partir de templates (Ref. RF-04, RF-06 e RF-11).

# Tarefa:
1. **Regras do Firebase Storage (Security Rules):**
   - Criar regras para o bucket limitando uploads apenas para usuários autenticados (`request.auth != null`).
   - Restringir o tamanho do arquivo a 5MB e aceitar apenas MIME types de imagem (`image/jpeg`, `image/png`, `image/webp`).
   - Garantir que apenas o dono da conversa possa fazer upload no caminho `/conversations/{conversationId}/{fileName}`.

2. **Cloud Function `generateTicket`:**
   - Criar uma função HTTPS Callable que recebe o `conversationId` e o `templateId`.
   - A função deve buscar o histórico das mensagens (Firestore) e o template selecionado (Firestore).
   - Enviar tudo para o Gemini com a instrução de preencher os placeholders `{{campo}}` do template usando o contexto da conversa.
   - Retornar o texto formatado para o Frontend (sem salvar no histórico do chat).

# Restrições:
- Sanitização de inputs para evitar chamadas maliciosas à Cloud Function.
- Otimização de custos: Na função de ticket, enviar apenas as últimas 10 mensagens relevantes da conversa para o LLM.
