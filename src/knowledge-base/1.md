# Regras de Negócio a implementar agora:
1. **Autenticação (Ref. RF-01 e RF-02):**
   - Usar Firebase Authentication (Email/Password).
   - Implementar proteção contra força bruta (já nativo do Firebase, mas garantir tratamento de erros de limite no front: `auth/too-many-requests`).

2. **Modelagem de Dados no Firestore (Ref. Seção 5):**
   Traduza o modelo relacional original para coleções NoSQL. Crie um arquivo `firebase/schema.ts` apenas com os tipos/interfaces TypeScript detalhando esta estrutura:
   - Coleção `users`: { email, nome, role: 'admin'|'user', ativo: boolean, deve_trocar_senha: boolean, criado_em, ultimo_login_em }. O ID do doc deve ser o UID do Firebase Auth.
   - Coleção `conversations`: { userId, title, topicId (opcional), createdAt, updatedAt, isArchived, isDeleted }.
   - Sub-coleção `messages` (dentro de conversations): { role: 'user'|'assistant'|'system', content, createdAt, metadata: { model, tokensIn, tokensOut, latencyMs }, citedSources: string[] }.
   - Coleção `knowledge_modules`: { slug, name, description, order }.
   - Sub-coleção `folders` e `files` dentro dos módulos contendo o conteúdo Markdown.
   - Coleção `system_config` (Doc único 'llm_config'): { modo, modeloDefault, maxTokens, temperature }.
   - Coleção `audit_log`: { userId, acao, detalhes, ip, createdAt }.
