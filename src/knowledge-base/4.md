# Atuação: Desenvolvedor Frontend Sênior (Next.js, React 19, Tailwind)
# Contexto: 
Implementação da tela principal do usuário (Chat) e suas integrações (Ref. RF-04, RF-05 e RF-06).

# Tarefa:
Desenvolver a experiência principal de conversação:

1. **Sidebar de Histórico (RF-05):**
   - Listar conversas do usuário ordenadas por data usando escuta em tempo real (`onSnapshot` do Firebase).
   - Implementar agrupamento por "Tópicos" e opções de renomear e arquivar (Soft-delete via atualização no Firestore).
   - Layout colapsável para dispositivos móveis (Mobile First).

2. **Interface do Chat e Composer (RF-04):**
   - Área de mensagens com auto-scroll.
   - Input de texto com suporte a envio por `Enter` (e `Shift+Enter` para nova linha).
   - Botão de anexo de imagens (com preview de até 10 imagens antes do envio, fazendo upload no Firebase Storage e obtendo a URL pública).
   - Componente visual para mostrar metadados da resposta da IA (Modelo usado, tokens, latência).

3. **Renderização de Markdown Avançada:**
   - Usar bibliotecas como `react-markdown`.
   - Suportar Syntax Highlighting para blocos de código.
   - Suportar renderização de fórmulas matemáticas (KaTeX) e diagramas (Mermaid.js).
   - Renderizar as `citedSources` (fontes citadas) como pequenos "Badges" ou links clicáveis no rodapé de cada mensagem do assistente.

4. **Ações de Mensagem e Exportação (RF-06 e RF-11):**
   - Botão de "Copiar" em cada mensagem.
   - Modal de "Exportar Chamado": O usuário seleciona um template, o Frontend chama a função `generateTicket`, exibe o loading e depois mostra o resultado final para cópia.
   - Botão para exportar a conversa inteira em `.md` ou `.json`.

# Restrições de UI/UX:
- A interface deve lidar graciosamente com o estado de "Streaming" ou "Loading" enquanto aguarda a Cloud Function do chat.
- Seguir o Design System com TailwindCSS e daisyUI, garantindo contraste (WCAG AA) tanto no modo claro quanto no escuro.
